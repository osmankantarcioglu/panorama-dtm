# Referans logoları

V5'teki (`/v5-endustri/`) kayan referans şeridi, logo dosyalarını **bu klasörden**
otomatik alır. Dosya yoksa kurumun baş harfleri (monogram) gösterilir — sayfa
her hâlükârda düzgün görünür.

## Nasıl eklenir

Dosyayı aşağıdaki adla bu klasöre koyun. Sayfayı yenilediğinizde monogram
otomatik olarak logoyla değişir; kodda değişiklik gerekmez.

| Dosya adı | Kurum |
|---|---|
| `deniz-kuvvetleri.svg` | Deniz Kuvvetleri Komutanlığı |
| `hava-kuvvetleri.svg` | Hava Kuvvetleri Komutanlığı |
| `kara-kuvvetleri.svg` | Kara Kuvvetleri Komutanlığı |
| `roketsan.svg` | ROKETSAN |
| `mke.svg` | MKE (Mühimmat + Barut ve Patlayıcı Fabrikası, ortak) |
| `euas.svg` | EÜAŞ Elektrik Üretim A.Ş. |
| `aydem.svg` | Aydem Enerji |
| `eren-holding.svg` | Eren Holding |
| `kardemir.svg` | Kardemir Demir Çelik |
| `koc-metalurji.svg` | Koç Metalurji |
| `kaptan-demir.svg` | Kaptan Demir Çelik |
| `turkiye-seker.svg` | Türkiye Şeker Fabrikaları |
| `tarim-kredi.svg` | Tarım Kredi Kooperatifleri |
| `et-sut-kurumu.svg` | Et ve Süt Kurumu |
| `ttk.svg` | Türkiye Taşkömürü Kurumu |
| `ege-linyitleri.svg` | Ege Linyitleri İşletmesi |

## Dosya gereksinimleri

- **Biçim:** SVG tercih edilir. PNG kullanacaksanız uzantıyı `.png` yapıp
  `v5-endustri/index.html` içindeki ilgili `src` satırını da güncelleyin.
- **Zemin:** Şerit koyu zeminde. Şeffaf zeminli, açık renkli ya da tek renk
  beyaz sürümler en iyi sonucu verir.
- **Boşluk:** Logonun kendi kenar boşluğu az olsun; kutu içinde %80 alana
  sığdırılıyor.
- Varsayılan olarak gri tonlamalı gösterilir, üzerine gelince kendi rengine döner.

## Önce izin alın

Bu logolar üçüncü tarafların tescilli markalarıdır. Referans olarak
yayımlamadan önce her kurumdan yazılı kullanım izni alın. TSK komutanlık
armaları ve MKE/ROKETSAN markaları için bu özellikle önemlidir; devlet
armalarının izinsiz ticari kullanımı Türkiye'de ayrıca sınırlıdır.

İzin alınamayan kurumlar için monogram gösterimi bırakılabilir — kurum adını
metin olarak anmak, logosunu kullanmaktan farklı bir izin rejimine tabidir.
